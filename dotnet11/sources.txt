Notes on this solution
- Built and verified against the .NET 11 Preview 6 SDK (11.0.100-preview.6.26359.118), the highest
  globally-installed SDK at authoring time.
- A handful of projects need the .NET 11 Preview 7 SDK (11.0.100-preview.7.26381.103) because the API
  they demonstrate only landed in that preview. Those project folders each carry their own global.json
  pinning the Preview 7 SDK - install it (e.g. via dotnet-install.ps1/.sh with -Channel 11.0 -Quality
  preview) before opening/building them if you don't already have it.
- Several APIs described in the devblogs prose didn't match what actually ships (renamed members, extra
  required calls, etc.) - each affected project's comments call out what was verified empirically against
  the installed SDK/reference assemblies rather than trusted from the blog text as-is.
