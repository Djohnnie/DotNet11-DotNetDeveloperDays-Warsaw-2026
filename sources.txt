Notes on this solution
- Built and verified against the .NET 11 RC 1 SDK (11.0.100-rc.1.26425.128), the highest
  globally-installed SDK at authoring time.
- Every project folder that carries a global.json pins that RC 1 SDK with rollForward
  "latestFeature" - install it (e.g. via dotnet-install.ps1/.sh with -Channel 11.0 -Quality
  preview) before opening/building the solution if you don't already have it.
- SOURCES.md is the documentation companion to this solution: the numbered solution folders
  follow the exact order of the feature recaps in SOURCES.md.
- A few documented features are intentionally not demoed by a project because they describe
  SDK/build or runtime-host behaviour rather than an API surface: improved test runs,
  reproducible containers, tar support and MSBuild glob exposure, and runtime-managed async.
- Several APIs described in the devblogs prose didn't match what actually ships (renamed members, extra
  required calls, etc.) - each affected project's comments call out what was verified empirically against
  the installed SDK/reference assemblies rather than trusted from the blog text as-is.
